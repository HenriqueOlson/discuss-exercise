# Library events browsing prototype

A web-first, single-screen prototype for the Discuss product design exercise. It helps library events coordinators browse events across branches, find work that needs attention, and revisit past events.

## Open the prototype

Open `index.html` in a browser. There is no build step, server, or external dependency.

## What you can explore

- Select multiple action-to-take cards to see events matching any selected action.
- Filter by one or more branches, timeframe, and event status.
- Try a natural-language search phrase to apply filters and find matching events.
- Sort the event list by latest or earliest date and time, and move through pages.
- Explore empty results, custom date validation, cancelled events, overdue actions, and missing artwork.

The event data is synthetic and generated in `app.js` relative to the day the page is opened. Search interpretation is simulated for the prototype.
